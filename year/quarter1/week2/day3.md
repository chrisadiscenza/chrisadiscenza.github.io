## <b> What is a set</b>

<b>Definitions </b>

 Set: A <b>set</b> is a collection of things that we call elements. We use brackets for set notation. 
 
 For example we write the set containing the first four letters as $A=\left{ a, b, c, d\right}$. 



 <b>Elements</b>: The things contained in a set.

 We write $b\in A$ to mean that $b$ is an element of the set $A$. 

 <b>Empty Set</b>: The set with no elements. We write $\left{ a, b, c, d \right}$ Or simply $\emptyset$.

<b>Union</b>: The set of elements in $A$ <b>or</b> $B$ for any two sets $A, B$. Looesly speaking, the union of two sets is the  collection of elements in $A$ combined with the elements in $B$. Note the key word: or used in the definition. As discussed in the logic section, the word <b>or</b> carries less information and that shows up here as the union of two sets is less specific about which elements are contained in it.

<b>Intersection</b>: The set of elements in $A$ <b>and</b> $B$ for any two sets $A, B$. The intersection describes the overlap between two sets. In other words it's the set of elements that are in both sets. If two sets have nothing in common then their intersection is the empty set. 

<b>Complement</b> The set of elements <b>not</b> in $A$. We write this as $\bar{A}$. 

This set can get complicated and out of hand the more creatively we think about it. Consider the set $C$ of all cats. Then elements in $\bar{C}$ could be a dog, a mouse, or the concept of empathy. Anything you can think of that is not a cat is an element of $\bar{C}$. This includes the set $C$ of cats! So we have that $C\in \bar{C}$. But that's not all! Is $\bar{C}$ a cat? No! So it's also in the complement of $C$. This means that $\bar{C}\in \bar{C}$. In other words, we have a set that is an element of itself! 

This might seem weird but its perfectly ok. You might just need to reread it a few times. Now it becomes not ok when you take the above discussion beyond the set of cats and ask about the set of all sets. This broke math for a few years until some rules and restrictions were put in place. This is a story for another class that goes beyond our discussion. 

<b>Subset</b>: A subset $B$ of $A$ means that any element in $B$ <b>implies</b> it's an element of $A$. 

<b>Cardinality</b>: The number of elements in a set. 

Have the students write down examples of sets then have them find the union, intersection and complement of their sets.
